Using OMTake with OBS Studio

OMTake sends a standard OMT (Open Media Transport) stream, so any app that receives OMT can use it. vMix supports OMT natively. OBS Studio receives it through the free OMT plugin, which adds an OMT Source that picks up OMT streams on your local network.

What you need

  • An iPhoneiOS 16.6 or later, with OMTake
  • OBS Studio 31 or laterWindows, macOS or Linux
  • The OMT pluginFree, open source, MIT license
  • One local networkShared by the iPhone and the OBS computer

The OMT plugin is a third-party plugin from the Open Media Transport project. OMTake is an independent app and is not affiliated with or endorsed by the OBS Project.

Setup in 3 steps

  1. Install the OMT plugin for OBS

    Download it from the plugin releases on GitHub, then:

    • Windows: download the Windows binaries and copy omtplugin.dll and libvmx.dll into C:\ProgramData\obs-studio\plugins\omtplugin\bin\64bit. Create the folder if it does not exist.
    • macOS: download the macOS .pkg and install it.
    • Linux: the plugin has to be built from source. Follow the Linux instructions in the README.

  2. Start streaming from OMTake

    Put the iPhone on the same local network as the OBS computer. Open OMTake, allow Camera, Microphone and Local Network access, and tap the red button.

  3. Add an OMT Source in OBS

    In OBS, add a new OMT Source and select the iPhone running OMTake.

For anything else about the plugin (other drives, Linux builds, updates), see the official OMT plugin README.

vMix-only features

The video and audio stream is plain OMT, so it is the same in OBS and in vMix. Tally (the green / red border and the rear torch) is available in vMix only.
